Como ler este relatório

Explicação simples · toque de novo no ? para fechar

{% if rel_help == "hub" %}

Aqui ficam os números da loja em formato de lista. Cada cartão abre um tipo de análise. Use o período (quando tiver) e o botão Atualizar.

Vendas — o que mais saiu, curva ABC, grupos, marcas, margem, comparativo e formas de pagamento.
Estoque — validade, giro/parado, ruptura, inventário valorizado, resumo, mín/máx, sem custo, zerados e etiquetas.
Equipe e clientes — operador, ranking de clientes e comissão estimada.
{% elif rel_help == "curva_abc" %}

A Curva ABC ordena os produtos do que mais faturou para o que menos faturou. Serve para ver o que segura a loja e o que é “resto”.

A~80% do $
B~15% do $
C~5% do $
  • #Posição no ranking (1 = quem mais faturou).
  • CLASSEA, B ou C — conforme a fatia acumulada do faturamento.
  • CÓDIGO GMCódigo interno do produto na loja.
  • PRODUTO / CATEGORIANome e grupo do cadastro.
  • TOTAL R$Quanto esse produto vendeu no período (em reais).
  • %Fatia só deste produto no total do período (ou da categoria filtrada).
  • % ACUM.Soma deste + todos os de cima. Quando chega perto de 80%, termina a classe A.
{% elif rel_help == "mais_vendidos" %}

Lista o que mais (ou menos) saiu no período. Dá para ordenar por dinheiro ou por quantidade.

  • #Colocação no ranking.
  • CÓDIGO GM / PRODUTOIdentificação do item.
  • QTDQuantidade vendida (unidades / kg etc.).
  • TICKET MÉDIOValor médio por unidade vendida (Total ÷ Qtd).
  • TOTAL R$Faturamento desse produto no período.
{% elif rel_help == "vendas_grupo" %}

Mostra o faturamento por categoria (ex.: Rações, Sacaria) — útil para ver qual prateleira puxa a loja.

  • GRUPOCategoria do cadastro.
  • SKUsQuantos produtos diferentes daquele grupo venderam.
  • QTDQuantidade total vendida no grupo.
  • TOTAL R$Dinheiro que o grupo gerou.
  • %Quanto esse grupo representa do faturamento total do período.
{% elif rel_help == "vendas_marca" %}

Mostra o que cada marca vendeu no período. Dá para ordenar por valor total (R$) ou por quantidade.

  • MARCANome da marca no cadastro (sem marca = “Sem marca”).
  • SKUsQuantos produtos diferentes daquela marca venderam.
  • QTDQuantidade total vendida da marca.
  • TOTAL R$Dinheiro que a marca gerou.
  • %Fatia dessa marca no faturamento total do período.
{% elif rel_help == "margem" %}

Margem = o que sobrou depois de tirar o custo. Ajuda a ver o que vende bem e deixa lucro.

  • CÓDIGO / PRODUTO / QTDO quê e quanto vendeu.
  • VENDA R$Total que o cliente pagou.
  • CUSTO R$Custo do cadastro × quantidade.
  • MARGEM R$Venda menos custo (lucro bruto em reais).
  • MARGEM %Lucro em porcentagem da venda (ex.: 30% = a cada R$ 100, sobram R$ 30).
{% elif rel_help == "comparativo" %}

Compara dois períodos lado a lado (ex.: este mês × mês passado) para ver se a loja subiu ou caiu.

  • INDICADORO que está sendo medido (cupons, faturamento, itens…).
  • PERÍODO ANúmeros do filtro de cima (De / Até).
  • PERÍODO BNúmeros do período B (mês passado ou datas que você escolheu).
  • VARIAÇÃO %Quanto A mudou em relação a B. Positivo = cresceu; negativo = caiu.
{% elif rel_help == "formas_pagamento" %}

Mostra como o cliente pagou: dinheiro, cartão, fiado etc.

  • FORMATipo de pagamento.
  • LANÇAMENTOSQuantas vezes aquela forma apareceu (uma venda pode ter mais de uma forma).
  • TOTAL R$Soma em reais daquela forma.
  • %Fatia daquela forma no total do período.
{% elif rel_help == "giro" %}

Duas listas no mesmo lugar: o que gira rápido e o que está parado com saldo.

Estoque parado (90 dias)

  • ÚLTIMA VENDA — última vez que saiu (quanto mais antiga, pior).
  • ESTOQUE — quanto ainda tem na loja.
  • CUSTO / VALOR PARADO — dinheiro “preso” nesse estoque.

Top giro (30 dias)

  • QTD 30d / RECEITA 30d — quanto vendeu e quanto faturou nos últimos 30 dias.
  • ÚLTIMA VENDA — data da última saída.
{% elif rel_help == "ruptura" %}

Ruptura = produto que vendeu recentemente e o estoque zerou. É “falta na prateleira”.

  • CÓDIGO / PRODUTO / CATEGORIAQual item está faltando.
  • ESTOQUE C+VSaldo Centro + Vila. Aqui deve estar zerado (por isso entrou na lista).
  • JANELAFiltro “15 / 30 / 60 / 90 dias” = período em que o produto ainda vendeu.
{% elif rel_help == "operador" %}

Totais por quem registrou a venda no PDV (operador do caixa).

  • OPERADORNome de quem fechou a venda.
  • VENDASQuantos cupons / vendas.
  • TICKET MÉDIOValor médio por venda.
  • FRETESoma de frete nas vendas desse operador.
  • TOTAL R$Faturamento total daquele operador no período.
{% elif rel_help == "clientes" %}

Quem mais comprou no período — bons clientes para cuidar e fidelizar.

  • CLIENTE / DOCUMENTONome e CPF/CNPJ.
  • VENDASQuantas compras no período.
  • TICKETValor médio por compra.
  • TOTAL R$Quanto esse cliente gastou no período.
{% elif rel_help == "comissao" %}

Estimativa de comissão com base no % ou R$ cadastrado no produto. Não é meta de vendedor.

  • CÓDIGO / PRODUTO / QTD / VENDAO que vendeu e o total em reais.
  • COMISSÃO %Percentual cadastrado (se existir).
  • COMISSÃO R$/UNValor fixo por unidade (se existir).
  • ESTIMADA R$Conta aproximada da comissão daquele produto no período.
{% elif rel_help == "validade" %}

Lista lotes perto de vencer ou já vencidos — para evitar perda e priorizar a venda.

  • PRODUTO / LOTEItem e número do lote.
  • C+VEstoque Centro + Vila (saldo da loja).
  • VENC.Quantidade já vencida naquela linha.
  • VENCIMENTOData em que o lote vence.
  • SIT.Situação (próximo / vencido etc.).
  • BAIXA / GRAVARAções para dar baixa ou salvar ajuste (quando liberado).
{% elif rel_help == "inventario" %}

Inventário valorizado = cada produto com saldo da loja e o dinheiro que isso representa.

  • VALOR CUSTOSaldo × custo do cadastro — quanto a loja investiu nesse estoque.
  • VALOR VENDASaldo × preço de venda — quanto valeria se vendesse tudo.
  • SALDO C / VEstoque Centro e Vila (saldo Agro).
  • DEPÓSITOFiltro: valoriza só Centro, só Vila ou os dois somados.
  • EXCELBaixa a lista completa do filtro (a tela pode mostrar só os 500 primeiros).
{% elif rel_help == "estoque_min_max" %}

Mostra o que está fora da meta de estoque (mínimo ou máximo) cadastrada no produto.

  • ABAIXOSaldo menor que o mínimo — falta comprar / repor.
  • ACIMASaldo maior que o máximo — excesso parado.
  • ALERTATexto explicando Centro e/ou Vila.
  • SEM METAProduto sem mínimo/máximo cadastrado não aparece aqui.
{% elif rel_help == "estoque_resumo" %}

Soma o estoque por grupo (categoria, marca ou unidade) — visão rápida de onde está o dinheiro.

  • SKUs / SALDOQuantos produtos e quanto de quantidade no grupo.
  • VALOR CUSTO / VENDADinheiro investido e potencial de venda do grupo.
  • % VENDAFatia do potencial de venda total.
{% elif rel_help == "estoque_sem_custo" %}

Buracos no cadastro: tem saldo na loja, mas o custo está zerado — o valor do inventário a custo fica errado.

  • O QUE FAZERAbrir o cadastro e preencher o custo (ou conferir última NF).
  • SALDOSó entram produtos com saldo no depósito filtrado.
{% elif rel_help == "estoque_zerados" %}

Lista o que está zerado ou negativo no depósito escolhido — útil para conferência e ajuste.

  • ZERADOSSaldo exatamente zero.
  • NEGATIVOSSaldo abaixo de zero (erro de baixa / ajuste).
  • DEPÓSITOFiltro Centro / Vila / C+V muda o que conta como zero.
