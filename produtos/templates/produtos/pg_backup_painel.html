ZIP portável (JSONL + Excel + kit com env real e guias). Confidencial — contém senhas.

Rotina: marque todas → «Baixar ZIP» → guarde no PC/nuvem. Um ZIP basta — sem precisar do site depois. Pasta kit/ traz guias + render-env-atual.env (Environment real do Render).

Guia rápido — o que é cada coisa

Rotina (só download)

  1. Backup completo — marque todas → «Baixar ZIP». Dados + pasta kit/ (guias + render-env-atual.env com secrets reais).
  2. Backup parcial — desmarque categorias → ZIP menor (+ kit/ igual).
  3. Guarde cópias seguras. Não precisa exportar .env manual do Render — já vem no ZIP.

O que ainda não vem no ZIP

  • Código Git (deploy branch producao)
  • Dados dentro do Mongo ERP (credenciais Mongo vêm no .env)

Restore (precisa de servidor funcionando)

  • Desastre: novo Render → deploy → colar kit/render-env-atual.env (trocar DATABASE_URL) → migrate → superuser → Restore ZIP.
  • Rollback dados: loja fechada → Restore ZIP de ontem.
  • Parcial por categoria: marque só a categoria → só ela é substituída.
